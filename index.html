Conversión de bases

El valor de cada bit depende de su posición. La coma separa posiciones positivas y negativas.

… 2³   2²   2¹   2⁰ · 2⁻¹   2⁻² …
Binario → decimal
1011,01₂ = 8 + 2 + 1 + ¼ = 11,25₁₀
Ver el valor que aporta cada bit

Multiplica cada bit por el peso que tiene debajo y suma los resultados.

Bit1011,01
Posición2³2²2¹2⁰,2⁻¹2⁻²
Peso8421,½¼

Para pasar de binario a octal, agrupa de 3 en 3 bits. Para hexadecimal, agrupa de 4 en 4, desde la coma hacia los lados.

Octal · 000–111 → 0–7Hexadecimal · 0000–1111 → 0–F
¿Cómo se convierte?

Binario a decimal: multiplica cada bit por su potencia de 2 y suma. A la derecha de la coma se usan potencias negativas: 2⁻¹ = 0,5; 2⁻² = 0,25…

Decimal a binario: para la parte entera, divide sucesivamente entre 2 y lee los restos de abajo arriba. Para la parte fraccionaria, multiplica por 2 y anota cada parte entera, de izquierda a derecha. Las fracciones periódicas se aproximan; usa hasta 8 bits fraccionarios.

＋

Suma y resta

Suma en base 2: cuando una columna llega a 2, escribe 0 y acarrea 1.

0+0=0   0+1=1   1+1=10

Chuleta rápida: reglas de suma y resta
SUMA
0 + 0 = 0sin acarreo
0 + 1 = 1sin acarreo
1 + 0 = 1sin acarreo
1 + 1 = 10escribe 0, lleva 1
1 + 1 + 1 = 11escribe 1, lleva 1
RESTA
0 − 0 = 0sin préstamo
1 − 0 = 1sin préstamo
1 − 1 = 0sin préstamo
0 − 1 = 1pide 1 prestado

Al pedir prestado en binario, el 0 de esa columna pasa a valer 10₂ (dos en decimal); por eso 10₂ − 1₂ = 1₂.

¿Cómo se resta con complementos?

Para A − B con complemento a 1, invierte los bits de B, suma a A y, si hay acarreo final, añádelo al bit menos significativo (acarreo recurrente).

Con complemento a 2, invierte B y suma 1. Añádelo a A y descarta el acarreo final. Mantén el mismo número de bits en A y B.

⊙

Complementos

Los complementos convierten la resta en una suma. Trabaja siempre con una anchura fija.

C1(B) = invertir B
C2(B) = invertir B + 1
Con 4 bits
B = 0110 → C1 = 1001 → C2 = 1010
¿Cómo interpretar el resultado?

Si A ≥ B, ambos métodos dan el resultado positivo. Si A < B, el patrón queda en complemento: para recuperar el valor negativo en C1, invierte el resultado; en C2, invierte y suma 1. En C1 vuelve a sumarse el acarreo final; en C2 se descarta.
